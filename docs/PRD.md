# 生日蛋糕 App — PRD v0.1

> 工作名：待定（候选见文末）
> 平台：iOS（优先适配苹果折叠屏，兼容所有 iPhone）
> 市场：海外优先，英文为主语言
> 状态：概念 → MVP 定义

---

## 1. 一句话定位

**把手机变成桌上的一个生日蛋糕。** 关灯、围坐、唱歌、许愿、吹蜡烛——用最简单的祝福，表达最真挚的情感。

## 2. 要解决的问题

- 过生日时需要一首应景的生日歌，但现在大家只是打开音乐 App 随便放一首，没有仪式感。
- 很多场合没有真蛋糕、不能点蜡烛（办公室、酒店、异地视频、餐厅禁明火、临时起意）。
- 现有生日 App 普遍卡通、廉价、广告多，撑不起「情绪价值」。

## 3. 目标用户与场景

| 场景 | 说明 | 主要姿态 |
|---|---|---|
| 家庭/朋友聚会 | 手机立在桌上当蛋糕，全员围着唱 | 半折 |
| 办公室/临时庆祝 | 没准备蛋糕，掏出手机就唱 | 外屏 / 直板 |
| 餐厅禁明火 | 真蛋糕没法点蜡烛，用 App 补上吹蜡烛环节 | 半折 / 全展 |
| 异地视频 | 视频通话时把手机对着镜头，或分享录屏 | 全展 |
| 给孩子过生日 | 孩子反复吹蜡烛的互动本身就是乐趣 | 半折 |

## 4. 核心体验：生日仪式流程

```
准备（个性化） → 展开：蜡烛落下 → 唱歌：烛火燃烧 → 合上：许愿 → 打开：吹蜡烛 → 庆祝 → 纪念卡
```

1. **准备**：输入名字、年龄，选蛋糕和蜡烛样式、蛋糕文字、歌曲版本。可提前设置好，存为一个「生日」。
2. **展开 = 拆礼物**：打开手机，蜡烛从上方依次落下、插进蛋糕，轻微弹跳 + 触感反馈，随后逐根点燃。
3. **唱歌**：生日歌播放，下半屏歌词跟随高亮（名字自动填入）。蜡烛随时间燃烧变短，晃动手机火焰摇曳。
4. **合上 = 许愿**：歌曲结束，画面渐暗，提示「Close your eyes. Close your phone. Make a wish.」。合上后外屏显示「Wish sealed ✦」并有柔和光晕。
5. **打开 = 吹蜡烛**：重新展开，提示吹蜡烛。按气流强度熄灭对应数量的蜡烛，熄灭后飘起青烟。
6. **庆祝**：全部熄灭后，彩纸/光点落下，播放录音祝福（如有），满屏触感。
7. **纪念卡**：生成一张带名字、年龄、日期、蛋糕画面的卡片，可保存/分享。

> 非折叠设备：「合上」改为「把手机屏幕朝下扣在桌上」（距离传感器 + 加速度计判断），同样成立。

## 5. 折叠屏姿态设计

| 姿态 | 布局 | 用途 |
|---|---|---|
| 外屏（合上） | 竖屏单根蜡烛 + 「Sing now」按钮；许愿时显示「Wish sealed」 | 快速开唱、许愿 |
| 半折（L 形立在桌上） | 上半屏：蛋糕与烛光，正对寿星；下半屏：歌词、祝福文字、控制条 | **主场景** |
| 全展（4:3 宽幅） | 横向大蛋糕，可容纳更多蜡烛，适合合影和视频通话 | 合影、多人 |

设计原则：
- 姿态切换时画面连续过渡（蛋糕「升起」或「铺开」），不是硬切布局。
- 布局全部基于自适应尺寸，不写死屏幕尺寸数值。
- 折痕区域不放关键内容（火焰、文字）。

> ⚠️ 待验证：iOS 是否提供铰链角度 / 姿态检测 API。若无，用窗口尺寸变化 + 加速度计推断半折状态，并提供手动切换。

## 6. 核心交互规格

### 6.1 蜡烛落下（展开动画）
- 蜡烛按顺序从上方落下，带重力加速度和落地回弹。
- 每根插入时轻触感（UIImpactFeedback light），最后一根 medium。
- 点燃：火苗从小到大「呼」地燃起。

### 6.2 吹蜡烛（麦克风）
- 检测低频气流噪声能量，区分吹气与说话/歌声（吹气频谱更宽、偏低频、无明显音高）。
- **按强度决定熄灭根数**：弱吹只灭 1–3 根、其余剧烈摇晃；强吹全灭。
- 熄灭后每根飘一缕青烟，2–3 秒消散。
- 兜底：麦克风权限被拒时，可用手指在火焰上「划过」熄灭。

### 6.3 火焰摇曳（陀螺仪 / 加速度计）
- 火焰按惯性向运动反方向倾斜，再以弹簧阻尼回正，不是简单跟随手机角度。
- 待机时有自然微弱抖动（噪声驱动），每根蜡烛相位不同。

### 6.4 燃烧变短
- 蜡烛长度绑定歌曲总时长：唱完时约燃到一半，留出吹蜡烛的余量。
- 蜡油在顶部微微积聚、偶尔滴落（V2 细节）。

### 6.5 年龄蜡烛规则
- ≤ 20 岁：按实际根数。
- > 20 岁：自动切换为数字蜡烛（如「3」「5」），可手动改回。
- 支持「不显示年龄」。

## 8. 艺术方向

- **核心意象**：关了灯的房间里，手机是唯一的光源。
- 写实温暖，不卡通。深色背景，暖色烛光实时照亮蛋糕表面和文字（Metal shader 动态光照）。
- 火焰是品牌签名：要做到「看一眼就觉得像真的」。
- 播放时自动调高亮度、保持常亮，结束后恢复。
- 声音设计：点燃、熄灭、青烟都有细腻音效；整体克制。

## 9. 技术方案（初步）

| 模块 | 方案 |
|---|---|
| UI | SwiftUI，自适应布局 |
| 火焰 / 光照 / 烟 | Metal shader（SwiftUI `.layerEffect` / `.colorEffect`），必要时 MetalKit |
| 粒子（彩纸、烟） | SpriteKit 或自研 Metal 粒子 |
| 吹气检测 | AVAudioEngine 实时 FFT，低频能量 + 频谱平坦度 |
| 运动 | CoreMotion |
| 触感 | Core Haptics（与节拍同步） |
| 音频 | AVAudioEngine，多轨（歌曲 + 音效 + 录音） |
| 数据 | SwiftData 本地存储；V2 视需要接 CloudKit |
| AI 歌曲（V2） | 歌声合成服务，按名字生成并缓存；需评估成本与延迟 |

## 10. 商业模式（建议）

生日 App 使用频率低（一年几次），订阅不太适合，建议：
- **免费**：基础蛋糕 + 英文生日歌 + 全部核心交互（体验必须完整，口碑靠这个）。
- **一次性买断（Pro）**：全部蛋糕/蜡烛样式、全部语言和风格、纪念卡无水印。
- **按次消耗（V2）**：AI 定制歌曲点数。
- 不放广告——广告会直接毁掉仪式感。

## 11. 增长

- 纪念卡和录屏天然适合分享（Instagram Story / TikTok），保留轻量品牌水印（Pro 可去除）。
- 「远程收集祝福」链接本身就是拉新入口。
- 关键词方向：birthday candles app、blow out candles、happy birthday song app、virtual birthday cake。

## 12. MVP 范围

**包含**
- 半折主场景 + 外屏 + 全展 + 非折叠设备适配
- 开合仪式（展开落蜡烛、合上许愿、打开吹蜡烛）
- 交互 ①–④：落下、吹灭、摇曳、燃烧
- 名字 / 年龄 / 蛋糕文字 / 3 款蛋糕 / 3 款蜡烛
- 英文生日歌 + 少量其他语言，播放轮数可调
- 纪念卡
- Pro 买断

**不包含（V2）**
- AI 定制歌曲、录音祝福、远程收集祝福、更多风格与样式、CloudKit 同步

## 13. 成功指标

- 首次完成完整仪式（展开→吹灭）的比例
- 纪念卡 / 录屏分享率
- Pro 转化率
- 同一用户全年回访次数（家人朋友生日）
